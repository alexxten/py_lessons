## 1. Аргументы функций, `*args` и `**kwargs`

### Позиционные и именованные аргументы

В Python при вызове функции аргументы можно передавать двумя способами:

 - Позиционные аргументы (positional) — передаются в том порядке, в котором объявлены параметры функции.
 - Именованные аргументы (keyword args) — передаются с указанием имени параметра. Порядок не важен.

### *args и **kwargs
Используются, когда количество аргументов заранее неизвестно.
 - *args — принимает любое количество позиционных аргументов, упаковывая их в кортеж.
  - **kwargs — принимает любое количество именованных аргументов, упаковывая их в словарь.
BTW, сами названия args и kwargs — это соглашение, но символы * и ** обязательны.

## 2. Функции высшего порядка

Тут обязательно помним о том, что функции в питоне - тоже объекты, соотв вертеть их можно также как другие объекты.

Формально с инета:
```
В программировании (и в математике) функциями высшего порядка называются функции, которые выполняют одно (или оба) из этих действий:

Принимают одну (и более) функций в качестве аргументов.
Возвращают функцию в качестве результата.
```

## 4. Работа с файлами

Для работы с файлами рекомендуется использовать менеджер контекста with — он автоматически закрывает файл после работы.

Базовые режимы доступа:

'r' — чтение (по умолчанию)
'w' — запись (перезаписывает файл или создает новый)
'a' — добавление в конец файла
'b' — бинарный режим (добавляется к другим, например 'rb')

```
with open('file.txt', 'r', encoding='utf-8') as file:
    content = file.read() 
```

## 5. GET-запросы

Для HTTP-запросов пока что чаще всего используется библиотека requests.
GET-запрос — для получения данных с сервера.

```
import requests

url = "https://api.github.com/users/octocat"
response = requests.get(url)
```
Полезные атрибуты ответа:
```
response.status_code — код ответа (200, 404, 500 и т.д.)
response.text — ответ в виде строки
response.json() — ответ в виде словаря (если сервер вернул JSON)
response.content — ответ в байтах (для файлов, изображений)
```
