11. Найдите задачу с самым длинным заголовком (по количеству символов). Выведите её id, title и длину.
12. Выведите все задачи, в заголовке которых встречается слово "aut" (регистронезависимо).

16. Создайте новую задачу (словарь) с новым id (следующим после максимального), произвольным userId, заголовком и completed = False. Добавьте её в список и выведите обновлённый список.
17. Удалите из списка задачу с указанным id. Проверьте, что она действительно удалена.
18. Создайте два списка: один содержит только выполненные задачи, другой – только невыполненные.
19. Найдите все задачи, у которых длина заголовка меньше 10 символов (или заголовок пустой).
20. Напишите функцию, которая возвращает список задач, отсортированных по длине заголовка (от коротких к длинным).
21. Подсчитайте общее количество символов во всех заголовках задач.
22. Выведите первые 3 задачи с самыми длинными заголовками.

## 2. Анализ цен на товары
Вам нужно создать программу для анализа цен на товары. Данные о товарах хранятся в JSON-файле products.json. 
Программа должна анализировать цены, находить выгодные предложения и создавать отчеты.

### Задача 1: Загрузка данных из JSON
Напишите функцию load_products(filename), которая:
- Принимает имя JSON-файла
- Загружает данные и возвращает список товаров
- Обрабатывает возможные ошибки (файл не найден, неверный JSON)

### Задача 2: Фильтрация товаров с лямбда-функциями
Напишите функцию filter_products(products, *filters), которая:
- Принимает список товаров и произвольное количество лямбда-функций через *args
- Последовательно применяет все фильтры к товарам
- Возвращает отфильтрованный список
Пример использования:
```
# Найти все товары в наличии с ценой меньше 30000
in_stock = lambda p: p['in_stock']
price_filter = lambda p: p['price'] < 30000

result = filter_products(products, in_stock, price_filter)
```

### Задача 3: Поиск скидок
Напишите функцию find_discounts(products, **criteria), которая:
- Принимает список товаров 
- Через **kwargs принимает критерии поиска: min_discount, max_price, category
- Находит товары, у которых есть скидка (old_price > price)
- Возвращает список товаров со скидками, отсортированный по размеру скидки
Пример:
```
discounts = find_discounts(
    products, 
    min_discount=10,  # минимальная скидка в процентах
    max_price=40000,  # максимальная цена
    category="electronics"
)
```
### Задача 4: Статистика по категориям
Напишите функцию category_stats(products, *categories) которая:
- Принимает список товаров и названия категорий через *args
- Для каждой категории считает:
  - Количество товаров
  - Среднюю цену
  - Минимальную и максимальную цену
  - Общее количество товаров в наличии
- Возвращает словарь со статистикой

### Задача 5: Сохранение отчета
Напишите функцию save_report(products, filename, **options) которая:
- Принимает список товаров
- Через **kwargs принимает параметры отчета: format (txt/csv), include_discounts, sort_by
- Сохраняет отчет в указанный файл

### Задача 6: Основная программа
Создайте основную функцию analyze_prices(products_file, **settings), которая:
- Принимает имя файла с данными
- Через **kwargs принимает настройки анализа:
  - categories - какие категории анализировать
  - min_rating - минимальный рейтинг
  - discount_threshold - порог скидки для уведомления
  - report_file - файл для отчета
  - report_format - формат отчета

Функция должна:
- Загрузить данные из JSON
- Применить фильтры на основе настроек
- Найти товары со скидками
- Посчитать статистику по категориям
- Сохранить отчет
- Вернуть словарь с результатами анализа

Пример использования программы

```
# Настройки анализа
settings = {
    'categories': ['electronics', 'audio'],
    'min_rating': 4.0,
    'discount_threshold': 10,
    'report_file': 'price_report.txt',
    'report_format': 'txt',
    'sort_by': 'discount'
}

# Запуск анализа
results = analyze_prices('products.json', **settings)

# Вывод результатов
print(f"Всего товаров: {results['total_products']}")
print(f"Товаров со скидкой: {results['discounted_count']}")
print(f"Средняя скидка: {results['avg_discount']}%")
print(f"Отчет сохранен в {results['report_file']}")
```
Требования к реализации
Обязательно использовать:
- *args для передачи переменного количества фильтров или категорий
- **kwargs для передачи настроек в функции
- Лямбда-функции для фильтрации товаров
- Работу с JSON-файлами (чтение)
- Работу с текстовыми файлами (запись отчета)

Функции для реализации:

- load_products(filename)
- filter_products(products, *filters)
- find_discounts(products, **criteria)
- category_stats(products, *categories)
- save_report(products, filename, **options)
- analyze_prices(products_file, **settings)
