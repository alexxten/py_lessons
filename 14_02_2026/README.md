### 1. Типы данных

*   **Базовые типы:** `int` (число), `float` (дробное), `str` (строка), `bool` (правда/ложь).
*   **id():** У каждого объекта есть уникальный идентификатор — его id в памяти. Функция `id()` показывает этот номер.
*   **Изменяемость (mutable) vs Неизменяемость (immutable):**
    *   **Неизменяемые (`int`, `float`, `str`, `bool`, `tuple`):** Когда "меняем" значение переменной, Python *не изменяет* старый объект, а создает *новый* с другим `id`.
    *   **Изменяемые (`list`, `dict`, `set`):** Объект можно менять «внутри», его `id` останется тем же.

#### Про ключи словаря
Ключами могут быть только immutable (если совсем по-умному, то они должны быть хешируемы)ю
Почему ключи должны быть такими:
- Хэшируемость (Fast Lookup): Python использует хэш-таблицы для хранения словарей. Хэш-значение ключа вычисляется один раз, что позволяет находить данные мгновенно, как по индексу.
- Неизменяемость (Immutability): Если бы ключ мог измениться (как список), его хэш-значение тоже изменилось бы, и Python не смог бы найти значение по этому ключу. 



### 2. Условный оператор (`if-elif-else`)

*   **Задача:** Выбор ветки исполнения в зависимости от условий.
*   **Логика:** Проверяем `if`; если мимо — проверяем `elif` (сколько угодно); если всё мимо — срабатывает `else` (необязателен).

### 3. Функции (`def`)

*   Функция, аналог как в математике. Что-то передали на вход, что-то получили на выход (либо сделали что-то внутри функции)
*   **`def`:** Ключевое слово для создания функции.
*   **Аргументы:** Данные, которые функция принимает «на вход».
*   **`return`:** Данные, которые функция отдает «на выход». Если `return` нет, функция вернет `None`.
