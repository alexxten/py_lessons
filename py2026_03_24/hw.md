1. Создайте класс Animal, который при инициализации принимает:
```
name (имя, строка)
age (возраст в годах, число)
hunger_level (уровень голода: 0–100, по умолчанию 50)
```

Реализуйте методы:
```
make_sound() — возвращает строку "Животное издаёт звук" (будет переопределено)
move() — возвращает строку "{name} двигается"
eat() — уменьшает hunger_level на 10 (но не ниже 0) и возвращает "{name} поел. Голод: {новый_уровень}"
get_info() — возвращает строку "{name}, возраст: {age} лет, голод: {hunger_level}"
```

2. Реализуйте дочерний класс Lion (наследует Animal)

Переопределяет:
```
make_sound() → возвращает "Рррр! Рык льва!"
move() → возвращает "{name} грациозно крадётся"
```
Добавляет метод:
```
hunt() → возвращает "{name} охотится!" (увеличивает голод на 20, потому что тратит энергию)
```
