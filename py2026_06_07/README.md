## Магические методы

РЕКОМЕНДУЮ дополнительно почитать тут: https://habr.com/ru/articles/186608/

Это специальные методы в Python, которые начинаются и заканчиваются двойным подчеркиванием (`__`). Чаще всего они вызываются автоматически при использовании встроенных операторов или функций Python.

**Пример:**
- Когда вы пишете `len(obj)`, Python ищет у объекта метод `__len__`.
- Когда вы пишете `obj + 5`, Python ищет метод `__add__`.

Они позволяют вашим классам вести себя как встроенные типы (строки, числа, списки).

---

### `__new__` vs `__init__`

Разница простая:

1. **`__new__`** — это **строитель**. Он создает *пустой* объект в памяти.
2. **`__init__`** — это **отделочник**. Он наполняет уже созданный объект данными (атрибутами).

**Важно:** `__new__` вызывается **ДО** `__init__`.

### Схема работы:
```
Класс -> __new__() -> создает пустой объект -> __init__() -> заполняет атрибуты -> Готовый объект
```

## Шпаргалка по другим полезным магическим методам

| Метод | Что делает | Когда вызывается |
| :--- | :--- | :--- |
| `__str__` | Строковое представление для людей | `print(obj)`, `str(obj)` |
| `__repr__` | Строковое представление для разработчиков | `repr(obj)`, в отладчике |
| `__len__` | Длина объекта | `len(obj)` |
| `__getitem__` | Доступ по индексу | `obj[0]` |
| `__setattr__` | Установка атрибута | `obj.x = 5` |
| `__call__` | Объект как функция | `obj()` |
| `__add__` | Сложение | `obj + 2` |
