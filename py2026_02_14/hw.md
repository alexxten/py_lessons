# Валидация пароля юзверя

Написать неск функций для проверки адекватности пароля юзверя

1.  **Функция проверки длины:**
    *   Если длина пароля меньше 6 — вернуть `"Слишком короткий"`.
    *   Если от 6 до 10 — вернуть `"Средняя длина"`.
    *   Если больше 10 — вернуть `"Длинный"`.

2.  **Функция проверки наличия цифр:** проверяет, есть ли в строке хотя бы одна цифра. Какой возврат у функции - реши самостоятельно. Тут можно заюзать цикл и метод строк isdigit() либо! regex при желании

3.  **Функция проверки наличия заглавных букв:** проверяет, есть ли в строке хотя бы одна заглавная буква. Какой возврат у функции - реши самостоятельно. Тут можно заюзать цикл и метод строк isupper() либо! regex при желании

4.  **Главная функция оценки надежности.** Внутри она должна:
    *   Вызвать функцию проверки длины и сохранить результат.
    *   Проверить наличие цифр и заглавных букв с помощью соответствующих функций.
    *   Вывести итог:
        *   Если пароль `"Слишком короткий"` — сразу сообщить об этом и не проверять дальше.
        *   Если длина нормальная (средняя или длинная), и есть **и** цифры, **и** заглавные буквы — написать: `"Отлично! Пароль ... , содержит цифры и заглавные буквы. Надежный пароль!"`.
        *   Если длина нормальная, но нет ни цифр, ни заглавных — написать: `"Пароль ... , но не содержит ни цифр, ни заглавных букв. Слишком простой."`.
        *   Если не хватает только цифр — написать: `"Пароль ... , но не содержит цифр. Добавьте хотя бы одну цифру."`.
        *   Если не хватает только заглавных букв — написать: `"Пароль ... , но не содержит заглавных букв. Добавьте хотя бы одну заглавную букву."`.

    В этом пункте тебе нужно в теле функции вызвать другие функции, это изи:
```commandline
def a() -> int:
    print()
    
def b() -> int:
    vyzov_a = a() -- вызвали другую функцию
    return vyzov_a + 2
```


# Что-то вроде To-Do лист
Пишем код "как будто по тзшке" для списка задач юзверя

### Функции для классификации задач

1.  **Функция `determine_priority(deadline_days)`**:
    *   Принимает количество дней до дедлайна (целое число).
    *   Возвращает приоритет задачи:
        * `deadline_days < 0` → `"Просрочено!"`
        * `1 <= deadline_days <= 3` → `"Высокий приоритет"`
        * `4 <= deadline_days <= 7` → `"Средний приоритет"`
        * `deadline_days > 7` → `"Низкий приоритет"`

2.  **Функция `get_status_symbol(status)`**:
    *   Принимает статус задачи (строка: `"новая"`, `"в работе"`, `"готова"`).
    *   Возвращает эмодзи или символ для красивого отображения:
        *   `"новая"` → `"🆕"`
        *   `"в работе"` → `"⚙️"`
        *   `"готова"` → `"✅"`
        *   Любое другое значение → `"❓"`

### Функции для работы с файлом

3.  **Функция `save_task(task_name, priority, status_symbol, deadline_days)`**:
    *   Принимает: название задачи, приоритет (из первой функции), символ статуса (из второй функции), и количество дней до дедлайна.
    *   Записывает строку в файл `tasks.txt` в формате:
        ```
        Название: Купить подарок | Статус: ⚙️ | Приоритет: Высокий приоритет | Дней до дедлайна: 2
        ```
    *   Возвращает `True` при успехе.

4.  **Функция `show_tasks_by_priority(priority_filter)`**:
    *   Принимает строку с приоритетом для фильтрации (например, `"Высокий приоритет"`).
    *   Открывает файл `tasks.txt` для чтения (`'r'`).
    *   Если файла нет — выводит `"Список задач пуст."`
    *   Если файл есть — читает все строки и выводит только те, где приоритет совпадает с `priority_filter`.
    *   Считает и выводит количество таких задач.

5.  **Функция `count_tasks_by_status()`**:
    *   Открывает файл `tasks.txt` для чтения.
    *   Создает три счетчика: новые, в работе, готовые.
    *   Проходит по всем строкам, смотрит на статус (эмодзи) и увеличивает соответствующий счетчик.
    *   Выводит статистику:
        ```
        Статистика задач:
        Новые: 3
        В работе: 2
        Готовые: 5
        Всего задач: 10
        ```

### Главная функция программы

6.  **Функция `main()`**:
    *   Выводит меню:
        ```
        1. Добавить новую задачу
        2. Показать все срочные задачи (Высокий приоритет)
        3. Показать статистику по статусам
        4. Выход
        ```
    *   Запрашивает у пользователя выбор (погугли input(), например https://www.w3schools.com/python/ref_func_input.asp). В целом обработка инпута необязательна, можешь просто данные перекидывать в функции, тк этот момент непринципиален.
    *   Использует `if/elif/else` для обработки:
        *   Если `1`:
            *   Запрашивает название задачи.
            *   Запрашивает статус (новая/в работе/готова).
            *   Запрашивает количество дней до дедлайна.
            *   Вызывает `determine_priority` для определения приоритета.
            *   Вызывает `get_status_symbol` для получения символа статуса.
            *   Вызывает `save_task` для сохранения в файл.
        *   Если `2`:
            *   Вызывает `show_tasks_by_priority` с параметром `"Высокий приоритет"` (и отдельно для `"Срочно! (сегодня)"`, если хотите усложнить).
        *   Если `3`:
            *   Вызывает `count_tasks_by_status`.
        *   Если `4`:
            *   Завершает программу.
        *   Иначе:
            *   Выводит `"Неверный выбор."`
