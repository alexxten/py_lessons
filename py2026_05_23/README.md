## 1. Цикл while (цикл с условием)

Цикл while повторяет блок кода до тех пор, пока указанное условие остается истинным (True). 
Как только условие становится ложным (False), цикл завершается.

**Важно**: Если условие изначально ложно, код внутри цикла не выполнится ни разу. 
Чтобы цикл не стал бесконечным, внутри него должно быть действие, которое рано или поздно изменит условие (например, счетчик или ввод пользователя).

В рамках while довольно часто используются конструкции:
- break — чтобы мгновенно выйти из цикла, игнорируя условие
- continue — чтобы пропустить остаток текущей итерации и перейти к следующей проверке условия

## 2. try-except-finally и создание своих исключений

Это механизм обработки ошибок (исключений), чтобы программа не падала с ошибкой, а реагировала контролируемо.
В целом не везде эту конструкцию любят, тк она усложняет читаемость, но в некоторых местах без нее никуда (часто при разработке бека например используется).

Логика конструкции:
- В блок try помещается код, который потенциально может вызвать ошибку.
- Если ошибка возникает, Python ищет подходящий блок except по типу ошибки и выполняет его (вместо аварийного завершения). Можно обрабатывать вообще любые исключения,  а можно только определенные:
```
try:
 ...
except Exception as e:  # Exception - общий класс всех исключений в питоне
 ...
```

либо
```
try:
 ...
except KeyError as e:  # отлавливаем только KeyError, если произойдут какие-либо другие ошибки - упадет программа
 ...
```

- Блок finally выполняется всегда, была ошибка или нет. Он нужен для "уборки": закрыть файл, освободить ресурсы.

Можно писать кастомные исключения для обраюботки собственной бизнес-логики. Для этого создаем класс, унаследованный от встроенного класса Exception.
Затем в нужном месте кода вы "кидаем" (с помощью raise) эту ошибку с понятным сообщением.
Это делает код чище и понятнее, когда нужно сообщить о специфической проблеме (например, "Не найден пользователь", "Операция не может быть проведена в неторговый день" и проч).

## 3. match-case (структурное сопоставление с образцом)

Появился в Python 3.10 (и напоминает switch-case из других языков). А еще немножко if-else.

Суть: передаем значение в match, а затем проверяем, какому образцу (case) оно соответствует. Python сравнивает не просто на равенство, а может "разбирать" структуру данных на части.

Что можно делать:
- Сравнивать с конкретными значениями (числами, строками).
- Объединять несколько вариантов через | (или).
- Распаковывать списки, кортежи, словари прямо в образце.
- Извлекать значения в переменные.

`case _:` — это блок "все остальное", аналог default.

Считается что он делает код более декларативным и наглядным по сравнению с громоздкими цепочками if-elif-else.

### 3.5. Немнооожечко про преобразование типов

В Python многие типы данных автоматически интерпретируются как True или False, когда используются в логическом контексте (например, в условии if, while, или с операторами and/or/not). 
Что считается False (ложью):
- None
- False (само логическое значение)
- Любой числовой ноль: 0, 0.0, 0j
- Пустые коллекции и последовательности: "" (пустая строка), [] (пустой список), () (пустой кортеж), {} (пустой словарь), set() (пустое множество)
- Пустые объекты-диапазоны типа range(0)

Что считается True (правдой):
- Всё остальное — любое ненулевое число, непустая строка, непустой список, словарь с хотя бы одним элементом и т.д. 
- Даже объекты, которые мы сами создаем, по умолчанию считаются True (если не определить специальный метод __bool__).
