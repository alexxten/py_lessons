## 1. Калькулятор
Реализовываем в директории `py2026_05_23/calculator` через класс и функции.
Напишите программу-калькулятор, которая запрашивает у пользователя два числа и операцию, а затем выводит результат.

Поддерживаемые операции:
- "+" — сложение
- "-" — вычитание
- "*" — умножение
- "/" — деление


Какие ошибки нужно обработать:

| Ошибка            | Когда возникает | Сообщение для пользователя |
|-------------------|----------|----------------------------|
| ValueError        | Ввели не число (буквы, символы)  | "Ошибка: Введите число, а не текст" |
| ZeroDivisionError | Деление на ноль   | "Ошибка: На ноль делить нельзя!" |
| Кастомный еррор   | Ввели неизвестную операцию (например, % или ^)  | "Ошибка: Неизвестная операция. Используйте +, -, *, /" |

И при успешном вычислении, и при любой ошибке, в конце выводится сообщение: 
"Калькулятор завершил работу".

Пример работы программы:

Пример 1 — успешное деление:

```
Введите первое число: 15
Введите второе число: 3
Выберите операцию (+, -, *, /): /
Результат: 15.0 / 3.0 = 5.0
Калькулятор завершил работу (с результатом или ошибкой)
```

Пример 2 — деление на ноль:
```
Введите первое число: 10
Введите второе число: 0
Выберите операцию (+, -, *, /): /
Ошибка: На ноль делить нельзя!
Калькулятор завершил работу (с результатом или ошибкой)
```

Пример 3 — ввод текста вместо числа:
```
Введите первое число: пять
Ошибка: Введите число, а не текст
Калькулятор завершил работу (с результатом или ошибкой)
```

Пример 4 — неизвестная операция:
```
Введите первое число: 8
Введите второе число: 2
Выберите операцию (+, -, *, /): ^
Ошибка: Неизвестная операция. Используйте +, -, *, /
Калькулятор завершил работу (с результатом или ошибкой)
```

### 2.1. Поиск по строке
Дана строка - символы и числа (типа "fhfhgkg!2gfgdfjgj56_р965r57"). Найти в ней самое большое число (в этой будет 965).
Т.е вычленяем из строки числа и ищем самое большое. Регулярки не используем.

### 2.2. Палиндром
Написать функцию, которая будет проверять что заданная строка является палиндромом. 
Ввели "А роза упала на лапу азора" - палиндром. Ввели "Вауууу" - это не палиндром.
